- "summary": 1-3 sentence summary of the key content
- "tags": 2-6 short lowercase topical tags (single words or-hyphenated), no "#" prefix

  - "text": short imperative sentence (e.g. 'Update the resume with ARIA deployment experience')

  - "due_date": format as YYYY-MM-DD if mentioned (resolving 'tomorrow', 'next monday', etc. relative to today); null if not mentioned
  - "repo": project or codebase name if referenced; null if not referenced

Use the same language as the note.
