# 0.7 — Timeline & activity depth

**Theme:** the tracker stops being a screensaver and becomes a record you can
query and correct.

**Rationale:** the collector works (Hyprland, idle-aware sessions, per-app
toggles, week view). Everything wrong with it today is either *it guessed wrong
and I can't fix it* (#54, #64, #66) or *it knows less than it could* (#53, #333,
#336). Fix those before adding scores and goals — a focus score computed over
un-editable sessions is decoration.

**Depends on:** nothing structural. **Blocks:** 0.8 (reports read sessions),
0.5 (#35 auto-complete).

## Data model

```sql
ALTER TABLE activity ADD COLUMN workspace TEXT;        -- #338
ALTER TABLE activity ADD COLUMN project TEXT;          -- #53
ALTER TABLE activity ADD COLUMN block_id TEXT;         -- #335 work blocks
ALTER TABLE activity ADD COLUMN idle_secs INTEGER NOT NULL DEFAULT 0;
CREATE TABLE session_edits (session_key TEXT PRIMARY KEY, note TEXT, applied_at TEXT);
```

Redaction (#66) applies at write time, not read time — redacted titles must not
exist in the DB at all if the point is that they were never stored.
