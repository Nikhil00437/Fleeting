# 0.12 — Desktop shell, CLI & Linux

**Theme:** the parts that live outside the browser tab.

**Rationale:** the Electron shell exists with a tray, auto-backend and the HUD
window. The CLI is a bash script. Both are the app's real ergonomics on a Linux
desktop, and both are currently thinner than the ideas list assumes.

**Depends on:** 0.11 (the CLI and IPC surfaces need the API token). **Blocks:**
0.13 (settings UI for shortcuts, shortcuts conflict UI).

## Deferred, on purpose

- #162 a TUI mode (Textual) — a second whole UI. Not a shell feature.
- #12 the browser extension — needs the Origin allow-list relaxed deliberately,
  which belongs with 0.11's token work, not here.
- #98 Windows/macOS fallback for the tracker — a different product.

## Cut / merge

- #461, #462, #470 are all "expose the same IPC as a scriptable surface". Build
  one `flee ipc <action> [args]` entry point; the Waybar module and the rofi mode
  are then one-line shell wrappers.
- #160 shell completions belong to whichever version lands the last new subcommand,
  practically this one.
