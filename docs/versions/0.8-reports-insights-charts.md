# 0.8 — Reports, insights & charts

**Theme:** the output. A daily report exists and a weekly digest exists; this
bundle makes them trustworthy, editable, evidence-linked and visual.

**Rationale:** reports are the product's promise. Right now a report is
generated once, read once and cannot be checked. #72 (edits survive
regeneration), #350 (evidence mode) and #73 (sections link to sources) are the
difference between "AI said something" and "here is what it saw".

**Depends on:** 0.7 (sessions must be correct), 0.5 (task states). **Blocks:**
0.9 (assistant reads reports), 0.11 (redacted export).

## Data model

```sql
ALTER TABLE daily_logs ADD COLUMN edited_body TEXT;   -- #72 human edit, kept
ALTER TABLE daily_logs ADD COLUMN prompt_override TEXT;-- #348 custom section prompt
ALTER TABLE daily_logs ADD COLUMN evidence TEXT;      -- #350 sentence → session refs
CREATE TABLE streaks (kind TEXT NOT NULL, day TEXT NOT NULL, count INTEGER,
  PRIMARY KEY (kind, day)) WITHOUT ROWID;
```
