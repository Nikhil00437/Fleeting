# 0.18 — DX, testing, ops & ecosystem

**Theme:** the bundle that makes the other fifteen cheaper.

**Rationale:** tests and CI are missing today (`b355330 test: add jsdom` is the
first one). Before more surface area lands, add the guardrails: type-check and
lint in CI, one typed client, an architecture doc, and the property tests that
protect the markdown/vault round-trip which 0.10 and 0.15 both rewrite.

**Depends on:** nothing. Do it early; the rest of the bundles get cheaper.

## Deferred, on purpose

- #196 a plugin or hook system for custom processors and #499 — do #497 (a
  documented Python hook API) first. If hooks are genuinely too limited, promote
  them to a manifest then, with evidence.
- #294 the MCP server needs 0.6's query parser to be the single parser. That is a
  dependency on 0.6, not on this bundle.

## Cut / merge

- #191 and #193 are the same CI story. One workflow, one pre-commit config, shared
  tool versions.
- #389 (JSON logging) and #395 (diagnostics bundle) are the same log pipeline.
- #295 (schema notes + query console) and #294 (MCP server) both need a
  documented read-only surface. Write it once.

## Order inside this bundle

1. #191 + #193 (CI, pre-commit) — fails the build on day one, then earns its keep.
2. #192 (typed client) — deletes hand-written `api.ts` fetch wrappers.
3. #391 + #392 (property and snapshot tests) — protects 0.10 and 0.15.
4. #189 (seed data) — unblocks #190 and #394.
5. #194 + #398 + #399 (docs) — last, so they describe what exists.
