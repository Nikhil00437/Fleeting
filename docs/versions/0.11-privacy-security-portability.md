# 0.11 — Privacy, security & portability

**Theme:** the app holds your whole work history and one `api_key`. Make that
auditable, revocable and portable.

**Rationale:** the README already flags the plaintext `api_key` and the
loopback-`Origin` issue. Those are not "future ideas" — they are known debt. This
bundle is deliberately self-contained: it touches auth, storage and export but
adds no new user-facing surface, so it can be reviewed on its own.

**Depends on:** 0.10 (export), 0.9 (per-source AI switches). **Blocks:**
nothing. Do it earlier than its number suggests.

## Data model

```sql
CREATE TABLE audit_log (id INTEGER PRIMARY KEY, at TEXT, actor TEXT,
  action TEXT, detail TEXT);
CREATE TABLE retention_policies (source TEXT PRIMARY KEY, keep_days INTEGER);
ALTER TABLE kv ADD COLUMN secret INTEGER NOT NULL DEFAULT 0; -- #140 keyring-backed rows
```
