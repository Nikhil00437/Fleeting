# 0.9 — Assistant & AI quality

**Theme:** the LLM stops being a black box. Everything here is about knowing what
it saw, controlling it, and letting it act without fear.

**Rationale:** chat, streaming, suggestions and actions already exist. What's
missing is the safety envelope: a preview of the exact context, a trace of which
queries it ran, confirm-before-act with undo, and a fallback chain so a down
Ollama degrades instead of failing.

**Depends on:** 0.6 (query parser), 0.4 (projects, sensitive flag).
**Blocks:** 0.11 (per-source "never use for AI" switches).

## Data model

```sql
ALTER TABLE notes ADD COLUMN enrich_confidence REAL;  -- #96
ALTER TABLE notes ADD COLUMN enrich_feedback INTEGER; -- #255 thumb up/down
ALTER TABLE notes ADD COLUMN claims TEXT;             -- #263 sentence → source span
CREATE TABLE llm_traces (id TEXT PRIMARY KEY, request_id TEXT, kind TEXT,
  context TEXT, tool_calls TEXT, tokens INTEGER, ms INTEGER, at TEXT);
CREATE TABLE prompt_prefs (key TEXT PRIMARY KEY, value TEXT); -- #255 learned prompt
CREATE TABLE saved_prompts (id TEXT PRIMARY KEY, name TEXT, body TEXT, at TEXT); -- #105
CREATE TABLE schedules (id TEXT PRIMARY KEY, cron TEXT, job TEXT, last_run TEXT);
```
