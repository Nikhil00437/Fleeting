# 0.6 — Search & recall

**Theme:** finding the thing you know you saved, and the answers you can get
from it.

**Rationale:** search exists (FTS5, optional embedding rerank, activity-aware
results). This bundle makes it queryable, tunable and conversational, and it adds
the navigation primitives — command palette, chip filters — that every later view
reuses.

**Depends on:** 0.4 (`note_links`, `trashed_at`, `type`). **Blocks:** 0.8, 0.15.

## Backend notes

- One query parser for FTS, the web UI and the future MCP server. Operator
  syntax (#313) belongs in a single module, not in three SQL strings.
- "Not relevant" (#321) needs a feedback table; do not abuse the embedding cache
  for it.

```sql
CREATE TABLE search_feedback (note_id TEXT NOT NULL, query TEXT NOT NULL, down INTEGER NOT NULL DEFAULT 1,
  PRIMARY KEY (note_id, query)) WITHOUT ROWID;
CREATE TABLE saved_searches (id TEXT PRIMARY KEY, name TEXT NOT NULL, query TEXT NOT NULL);
CREATE TABLE query_log (q TEXT PRIMARY KEY, hits INTEGER, last_at TEXT) WITHOUT ROWID;
```
