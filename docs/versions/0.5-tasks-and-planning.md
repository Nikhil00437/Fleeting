# 0.5 — Tasks & day planning

**Theme:** turning captured intentions into a day you can actually finish.

**Rationale:** tasks already exist with due dates, priority, repo and note links.
This bundle makes them schedulable and reviewable rather than just a checklist,
and it is the last bundle before the app has a "what should I do now" answer.

**Depends on:** 0.3 (templates produce tasks), 0.4 (projects, custom fields).
**Blocks:** 0.8 (charts need task states), 0.9 (assistant writes tasks).
