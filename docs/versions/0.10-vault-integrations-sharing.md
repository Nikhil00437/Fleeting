# 0.10 — Vault, integrations & sharing

**Theme:** getting data in and out of other tools.

**Rationale:** the markdown vault mirror already exists. This bundle hardens it
(#113 conflicts, #122 dry run), adds the ingestion sources that make the vault
worth maintaining, and adds one honest export path. It does **not** add sync —
that is 0.17, and it has different risk.

**Depends on:** 0.4 (`type`, `fields`, `trashed_at`, `sensitive`).
**Blocks:** 0.11 (redacted export builds on #143).

## Data model

```sql
ALTER TABLE notes ADD COLUMN frontmatter TEXT;   -- #114 schema-driven
ALTER TABLE notes ADD COLUMN provenance TEXT;    -- #473 filterable source
CREATE TABLE vault_sync_log (id INTEGER PRIMARY KEY, note_id TEXT, direction TEXT,
  hash_before TEXT, hash_after TEXT, conflict INTEGER DEFAULT 0, at TEXT);
CREATE TABLE ingested_sources (url TEXT PRIMARY KEY, title TEXT, fetched_at TEXT);
```

Vault writes already go through `services/markdown.py`. #113's three-way merge
needs the last-written hash per file, which means the sync log, not a stat().
