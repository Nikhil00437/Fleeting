# 0.15 — Knowledge work, learning & writing

**Theme:** long-form. Reading, editing, and the note as a working document
rather than an inbox item.

**Rationale:** every other bundle treats a note as a record. This one treats it
as text you write in and study from: a real editor, inline task syntax,
transcript highlighting, flashcards.

**Depends on:** 0.4 (`note_links`, `type`), 0.6 (find-similar for #320-driven
study flows). **Blocks:** 0.18 (fixtures for parser property tests).

## Data model

```sql
ALTER TABLE notes ADD COLUMN body TEXT;          -- markdown source, NULL = use title/summary
ALTER TABLE notes ADD COLUMN outline TEXT;       -- #206 cached heading tree
ALTER TABLE notes ADD COLUMN reading_secs INTEGER;
CREATE TABLE highlights (id TEXT PRIMARY KEY, note_id TEXT, kind TEXT,
  start_secs INTEGER, text TEXT, color TEXT);   -- #370 transcript + article
```
